1. Arsitektur & Konsep Dasar Sistem

Sistem ini menggunakan arsitektur Serverless yang memisahkan bagian antarmuka pengguna (Frontend) dan penyimpanan data (Backend):

  • Frontend: Di-host di GitHub Pages menggunakan file statis (HTML, CSS, JavaScript) agar dapat diakses super cepat lewat HP maupun Laptop kru lapangan.
  • Backend & Database: Menggunakan Google Sheets sebagai basis data utama dan Google Apps Script (GAS) sebagai API server untuk menangani perintah baca/tulis (*CRUD*).
  • Penyimpanan Foto: Foto yang diambil langsung dari kamera HP akan dikompres secara otomatis oleh browser, lalu dikirim ke server untuk disimpan di Google Drive khusus inventaris.

2. Hak Akses & Keamanan (Read-Only vs Admin Mode)

Untuk menjaga keamanan data dari kesalahan input oleh pihak luar, sistem menerapkan pembatasan hak akses berbasis LocalStorage:

  • 🟢 Read-Only Mode (Publik / Kru Umum): Saat pertama kali dibuka, tombol-tombol aksi berbahaya (Tambah, Massal, Edit, Hapus) disembunyikan secara otomatis. Pengguna hanya dapat melihat data, melacak status, dan mencetak laporan.
  • 🔴 Edit Mode Aktif (Admin / Kru Berwenang): Ditandai dengan indikator merah di sudut kiri atas web. Tombol aksi administratif akan terbuka penuh setelah sistem mendeteksi sesi login aktif.

3. Navigasi Utama, Tampilan, & Dark Mode

  • Grid View vs List View: Tombol toggle di sebelah kanan atas memampukan kru beralih antara tampilan kartu besar (Grid) yang kaya visual atau tampilan baris minimalis (List) untuk pemindaian data cepat.
  • Dark Mode Otomatis: Sistem mendukung mode gelap penuh yang ramah baterai dan nyaman digunakan saat pengecekan gudang di pencahayaan minim.

4. Pencarian, Filter Cerdas, & Mode Wadah

  • Kolom Pencarian Cepat: Ketik nama alat, merk, atau kode barang (misal: ADPT-JACK3.5 atau HRCS-018) untuk memfilter item secara instan.
  • Filter Pills (Tab Status/Lokasi): Menyaring item berdasarkan status cepat seperti Semua Alat, Akan Dibawa, Dipakai, Di Gudang, Perbaikan, hingga lokasi fisik (*Gudang Kanguru, Gudang Mrican, Event*).
  • Filter Tim: Tombol ⚙️ FILTER TIM membuka panel lanjutan untuk menyaring barang berdasarkan kategori tim (Speaker, Kabel, Booth, dll).
  • 📦 Tampilkan Semua vs 🧰 Hanya Wadah: Tombol khusus untuk menyembunyikan barang-barang eceran (kabel/adaptor kecil) dan hanya menampilkan wadah utamanya saja (Hardcase, Koper, Box). Sangat berguna saat proses hitung bagasi/bagasi truk.

5. Pemindaian Kode (Scan QR / Barcode)

Tekan tombol 📷 Scan QR di sebelah kotak pencarian untuk membuka kamera pemindai:

  • 🔄 Tombol Kamera: Membalik orientasi kamera (kamera belakang/depan).
  • 🔦 Tombol Senter: Menyalakan lampu kilat (*flashlight*) perangkat untuk memindai kode di sudut gudang yang gelap.
  • Mode Normal: Begitu QR/Barcode terbaca, sistem otomatis mengetik kodenya ke pencarian dan membuka detail barang tersebut.

6. Detail Item, Galeri Multi-Foto, & Zoom

Mengetuk salah satu kartu barang akan membuka jendela modal detail yang memuat:

  • Galeri Multi-Foto (Hingga 3 Foto): Foto fisik barang ditampilkan berdampingan. Mengetuk foto akan membuka penampil layar penuh (*Zoom Modal*) lengkap dengan tombol navigasi geser kiri-kanan.
  • Indikator Wadah (IN-BOX): Menunjukkan apakah barang tersebut tersimpan di dalam koper tertentu. Klik nama wadahnya untuk langsung melompat melihat data koper induknya.
  • Cek Silang Stok: Ringkasan otomatis jumlah total item serupa di seluruh gudang dan sebaran statusnya.
  • Isi di Dalam Wadah: Jika item yang diklik adalah sebuah Hardcase/Koper, sistem akan menampilkan daftar seluruh kabel atau alat kecil yang menumpang di dalamnya.

7. Operasi Data: Tambah, Edit, & Duplikat Alat

  • ➕ Tambah Alat: Membuka form input barang baru dengan fitur unggah hingga 3 foto, kompresi otomatis, pengaturan jumlah (*Qty*), kondisi, dan lokasi gudang awal.
  • ✏️ Edit Data / Foto: Memperbarui informasi teks, mengganti atau menghapus foto lama secara fleksibel.
  • 📋 Duplikat Alat (Fitur Baru): Berada di dalam menu detail item. Digunakan saat ada pembelian barang baru yang identik. Sistem akan menyalin seluruh detail, catatan, dan formula gambar/foto aslinya secara instan ke baris baru tanpa perlu repot *upload* ulang foto dari awal.

8. Operasi Massal (Bulk Mode), Misi Event, & Efek Domino

  • 🛒 Mode Pilih (Massal): Mengaktifkan mode centang pada banyak item sekaligus untuk melakukan pembaruan status massal (misal: memindahkan puluhan barang sekaligus ke status *Akan Dibawa*).
  • 🎯 Misi & Event Spesifik: Memasukkan barang terpilih ke dalam daftar pengiriman event. Sistem mendukung destinasi spesifik seperti:
    👉 "Akan Dibawa ke Gedung UTC Semarang"
    👉 "Akan Dibawa ke Gedung Pacific Yogya"
  • Efek Domino Wadah: Teknologi cerdas yang secara otomatis ikut menandai isi koper/hardcase ikut terbawa apabila koper utamanya dipilih untuk suatu misi, mencegah ada item printilan yang tertinggal di gudang (*🚨 TERTINGGAL Alert*).

9. Pelaporan: Cetak Manifest, CO-31, & Export Excel

  • 📄 Cetak Manifest / Surat Jalan: Mencetak daftar muatan resmi yang dikelompokkan rapi per gudang asal dan per koper/hardcase untuk ditaruh di kabin supir.
  • 📄 Cetak CO-31: Mencetak lampiran daftar barang resmi yang disesuaikan dengan format operasional form pengiriman *CO-31-IN*.
  • 📥 Export Excel (CSV): Mengunduh laporan inventaris dalam format CSV dengan opsi filter berdasarkan lokasi gudang, tim terkait, dan kondisi barang.

10. Tanya Jawab & Kendala Umum (Troubleshooting)

Kendala Penyebab Umum Solusi
Tombol aksi tidak muncul Sesi akses masih dalam mode Read-Only. Pastikan perangkat Anda memiliki izin admin atau muat ulang sesi login Anda.
Foto gagal di-upload Koneksi internet terputus atau ukuran file terlalu besar. Sistem sudah mengompres otomatis, namun pastikan jaringan stabil saat menekan tombol Simpan.
Data di web tidak berubah Memori *cache* browser masih menyimpan data lama. Lakukan *Hard Refresh* pada browser Anda (Ctrl+F5 di PC atau tarik layar ke bawah di HP).
