1. Status Masuk (Read-Only vs Edit Mode)

Sistem membagi akses menjadi dua mode untuk keamanan data:

  • 🟢 Read-Only Mode: Mode bawaan saat pertama kali membuka web. Tombol tambah, edit, atau ubah status disembunyikan agar data tidak sengaja terubah.
  • 🔴 Edit Mode Aktif: Muncul saat sesi admin/kru berwenang aktif. Seluruh tombol aksi operasional terbuka penuh.

2. Tampilan Kartu (Grid) vs List & Dark Mode

  • Grid View vs List View: Tombol di kanan atas untuk beralih antara tampilan kartu besar (Grid) atau tampilan baris minimalis (List) guna mempercepat pemindaian data.
  • Dark Mode: Menyesuaikan tampilan otomatis ke mode gelap untuk kenyamanan mata saat pengecekan di gudang minim cahaya.

3. Cara Cari Alat, Filter Tim, & Tombol "Hanya Wadah"

  • Kolom Pencarian: Ketik nama, merk, atau kode barang (misal: ADPT-JACK3.5 atau HRCS-018) untuk menyaring item secara instan.
  • Pill Filter: Menyaring item berdasarkan status cepat seperti Akan Dibawa, Dipakai, Di Gudang, Perbaikan, atau lokasi gudang.
  • Filter Tim: Tombol ⚙️ FILTER TIM untuk menyaring barang berdasarkan kategori tim (Speaker, Kabel, Booth).
  • 🧰 Hanya Wadah: Tombol pintas untuk menyembunyikan barang eceran dan hanya menampilkan **Hardcase, Koper, atau Box utamanya saja**. Sangat membantu saat proses hitung bagasi truk.

4. Cara Pakai Scan QR / Barcode & Mode Massal

Klik tombol 📷 Scan QR di sebelah kolom pencarian:

  • Scan Biasa: Cukup klik Scan QR, arahkan kamera ke kode barang. Sistem otomatis mencari dan membuka detail barang tersebut di layar.
  • Scan + Mode Massal (Pilih Banyak): Jika Anda mengaktifkan tombol Massal terlebih dahulu sebelum menekan Scan QR, kamera pemindai akan berfungsi untuk mencentang dan memilih banyak barang secara otomatis hanya dengan mengarahkan kamera ke satu persatu QR Code barang. Barang-barang yang di-scan akan langsung masuk ke daftar terpilih untuk di-update statusnya secara massal!
  • Tersedia juga tombol 🔄 Kamera (putar depan/belakang) dan 🔦 Senter di dalam layar scanner.

5. Klik Detail Alat, Galeri Foto, & Zoom

Ketuk salah satu kartu barang untuk membuka jendela detail:

  • Galeri Foto: Menampilkan hingga 3 foto fisik barang. Ketuk foto untuk memperbesar (*Zoom Modal*) dengan tombol geser antar-foto.
  • Badge IN-BOX: Menandakan item berada di dalam koper tertentu. Klik nama koper hijaunya untuk melompat langsung ke data koper induk.
  • Cek Silang Stok: Menampilkan total jumlah item serupa di gudang beserta sebaran statusnya saat itu.

6. Nambah Alat, Edit Data, & Fitur "Duplikat Alat"

  • ➕ Tambah Alat: Form untuk memasukkan item baru lengkap dengan unggah foto kamera, jumlah (*Qty*), kondisi, dan lokasi gudang.
  • ✏️ Edit Data / Foto: Memperbarui informasi teks, catatan, atau mengganti foto lama.
  • 📋 Duplikat Alat: Saat membeli barang baru yang jenis dan bentuknya persis sama dengan yang sudah ada, buka detail barang tersebut lalu klik Duplikat Alat. Sistem otomatis menyalin seluruh data, catatan, dan foto aslinya ke baris baru secara instan tanpa perlu repot upload ulang!

7. Pilih Massal (Bulk) & Kirim Misi (Semarang / Yogya)

  • Mode Pilih (Massal): Centang beberapa item sekaligus untuk memperbarui status secara bersamaan.
  • Misi & Event Spesifik: Saat menyiapkan pengiriman, masukkan nama event dan tentukan destinasi spesifik:
    👉 "Akan Dibawa ke Gedung UTC Semarang"
    👉 "Akan Dibawa ke Gedung Pacific Yogya"
  • Efek Domino Wadah: Memilih koper utama untuk dibawa ke event akan membuat sistem secara otomatis menandai seluruh kabel atau alat di dalam koper tersebut ikut berstatus *Akan Dibawa*, mencegah ada item kecil yang tertinggal di gudang (*🚨 TERTINGGAL*).

8. Cetak Surat Jalan (Manifest), CO-31, & Export Excel

  • 📄 Cetak Surat Jalan: Mencetak daftar muatan yang dikelompokkan rapi per gudang asal dan per koper untuk kru/supir.
  • 📄 Cetak CO-31: Format cetak lampiran barang yang disesuaikan dengan form pesanan pengiriman resmi *CO-31-IN*.
  • 📥 Export Excel: Mengunduh data inventaris dalam format CSV dengan opsi filter sesuai kebutuhan.

9. Tanya Jawab Cepat (Troubleshooting)

Kendala di Lapangan Penyebab & Cara Mengatasinya
Tombol tambah/edit tidak muncul? Perangkat berada dalam mode Read-Only. Pastikan sesi login admin/kru Anda aktif.
Data tidak berubah setelah disimpan? Memori browser menyimpan *cache* lama. Lakukan *refresh* halaman dengan menarik layar ke bawah.
Kamera scanner gagal terbuka? Izin browser untuk mengakses kamera belum diizinkan. Pilih "Allow/Izinkan" saat diminta akses.
